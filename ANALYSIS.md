# 🔍 Анализ репозитория через Claude API

Замыкает цепочку: подключённый репозиторий → Claude читает код → реальные
предложения появляются в Песочнице.

## Как настроить

### 1. Получи ключ Anthropic API
https://console.anthropic.com/ → API Keys → создай ключ (`sk-ant-...`)

### 2. Пропиши ключ в .env на сервере
```bash
cd /home/administrator/todo-app
nano .env
```
```
ANTHROPIC_API_KEY=sk-ant-твой-ключ
CLAUDE_MODEL=claude-sonnet-4-5
```
> ⚠️ Актуальные ID моделей смотри на docs.claude.com — поставь ту, что
> доступна твоему аккаунту. Если модель недоступна, анализ вернёт ошибку
> с текстом от API.

### 3. Перезапусти сервер
```bash
pm2 restart todo-app --update-env
```
(`--update-env` обязателен, чтобы PM2 подхватил новый .env)

### 4. Подключи репозиторий
Вкладка «Настройки» → впиши репозиторий → «Сохранить».
Для приватных репо добавь GitHub-токен (иначе лимит 60 запросов/час и
только публичные репо).

### 5. Запусти анализ
Вкладка «Настройки» → «Проанализировать репозиторий».
Через 15–40 сек находки появятся в Песочнице.

## Как это работает под капотом

1. `analyzer.js` берёт из настроек repo_url, ветку и токен
2. Через GitHub API тянет дерево файлов, фильтрует исходники
   (js, ts, py, html, css… — без node_modules, lock-файлов, бинарников)
3. Ограничения: до 40 файлов, до 120 KB суммарно, файл до 30 KB
   (чтобы уложиться в контекст и не раздувать стоимость запроса)
4. Собирает промпт с кодом и шлёт в Claude API (Messages endpoint)
5. Claude возвращает JSON-массив предложений (title, description,
   category, priority)
6. Парсер устойчив к markdown-обёрткам и пояснениям вокруг JSON
7. Новые предложения пишутся в песочницу; дубликаты по заголовку
   пропускаются — можно запускать анализ повторно

## Запуск из командной строки (без UI)

```bash
ANTHROPIC_API_KEY=sk-ant-... node analyzer.js
```

## Стоимость

Один анализ ≈ один запрос к Claude с кодом репо (до ~120 KB на входе +
до 4096 токенов ответа). По ценам Sonnet это центы за прогон. Точные
цифры — на anthropic.com/pricing.

## Настройки анализатора

В начале `analyzer.js` можно поменять:
- `MAX_FILES` — сколько файлов брать (40)
- `MAX_TOTAL_BYTES` — суммарный лимит (120 KB)
- `CODE_EXTENSIONS` — какие расширения анализировать
- `SKIP_DIRS` / `SKIP_FILES` — что пропускать

## Безопасность

- `ANTHROPIC_API_KEY` — только в .env (env var), не в БД, не на фронте
- GitHub-токен хранится в БД (таблица settings) в открытом виде —
  на своём VPS приемлемо, но кандидат на шифрование (есть в Песочнице)
- Ключ Claude никогда не отдаётся на фронт
