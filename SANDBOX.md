# 🤖 Песочница Claude

Отдельная вкладка, куда попадают предложения по улучшению проекта от ИИ:
находки при анализе кода, недочёты, идеи фич.

## Как это работает

1. Claude анализирует репозиторий и код проекта
2. Находки складываются в таблицу `sandbox` (через `seed_sandbox.js` или API)
3. На вкладке «Песочница Claude» они показываются карточками с категорией и приоритетом
4. Юзер **перетаскивает** карточку на вкладку «Общая доска» ИЛИ жмёт «→ В пулл»
5. Предложение становится обычной задачей (автор — тот, кто перетащил; тег «из Песочницы Claude»)
6. Ненужное можно «Скрыть» (dismiss)

## Первый запуск / наполнение песочницы

```bash
node seed_sandbox.js
```

Скрипт добавит стартовый набор находок, только если песочница пуста.

## Категории

| Категория | Что значит |
|-----------|-----------|
| security | Безопасность |
| performance | Производительность |
| feature | Новая фича |
| bug | Баг / потенциальная ошибка |
| refactor | Рефакторинг, тесты |
| improvement | Прочее улучшение |

## Приоритеты
`high` → `medium` → `low` (в списке сортируются от высокого к низкому)

## API

```
GET  /api/sandbox                 → список pending-предложений
POST /api/sandbox/:id/promote     → превратить в задачу общего пулла
POST /api/sandbox/:id/dismiss     → скрыть предложение
```

## Добавить своё предложение вручную

```bash
node -e "
const db = require('./db');
(async () => {
  await db.initDb();
  await db.addSandboxTask('Заголовок', 'Описание', 'feature', 'medium');
  console.log('добавлено');
  process.exit(0);
})();
"
```

## Как обновлять песочницу новыми находками Claude

Когда Claude снова просматривает код и находит новое — он добавляет записи
через `db.addSandboxTask(...)`. Можно расширить `seed_sandbox.js` новыми
пунктами или сделать отдельный endpoint для добавления (сейчас добавление
идёт через скрипт/код, а не через UI — так предложения остаются «от ИИ»,
а не пользовательскими).
